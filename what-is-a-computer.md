# What Is a Computer?

## What this is / why it matters
Before talking about servers, cloud, or networking, it helps to be precise about what actually counts as "a computer." The definition matters because it explains why so many different-looking devices (a laptop, a phone, a smart TV, a cloud server) are all, underneath, the same basic thing — and why all of them can be given an IP address and put on a network.

## How it works
A computer is any device that has:
- A **CPU** (does the processing)
- **RAM** (short-term working memory)
- **Storage** (long-term memory — files, OS, data)
- An **OS** (software that manages the hardware and runs applications)

Any device with those four things can be assigned an **IP address** and talk to other devices over a network. That's why the same core idea shows up in very different form factors:
- **Laptop** — general personal use
- **Server** — built to host applications and stay running, usually with no screen or keyboard attached
- **Mobile phone** — calling, apps, mostly used through a touchscreen
- **TV (smart TV)** — media playback, apps

The hardware and use case differ a lot, but all of them fit the same definition — which is exactly why a "server" isn't a special kind of magic box, it's just a computer that's provisioned and configured to run applications instead of being used directly by a person.

## Key takeaways
- "Computer" = CPU + RAM + Storage + OS, and if it has those, it can be network-addressable (assigned an IP).
- A server isn't fundamentally different hardware from a laptop — it's a computer configured and dedicated to hosting applications rather than personal use.
- This definition is why so many unrelated-looking devices (phones, TVs, laptops, cloud instances) can all be treated the same way from a networking standpoint.
